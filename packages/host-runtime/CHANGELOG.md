# 更新记录

## 0.14.3

- 独立 Shell 维护宿主框架；公开 application-loader 装配外部产品，提供受控加载、取消、释放与重开能力。
- 类型声明覆盖省略 descriptor 定义和双参数清理进度回调；仓库外消费验证同时检查 TypeScript 合同。

## 0.12.0

- 增加独立的公共资源来源选择接口：local 工作目录与 dev/prod Git 分支分别配置，不影响资料环境和授权中心。

## 0.9.5

- 资格记录已经过期清空时，退出或切换账户仍立即通知所有界面撤下旧身份。

## 0.9.4

- 同批资格查询只在同一账户代次内复用；新登录等待旧请求结束后重新核验，旧账户的动作仍拒绝执行。

## 0.9.3

- 账户启动后定期整批核对软件资格，购买、续费和网络恢复无需先进入个人中心刷新。
- 商城关闭只触发重新核对；业务操作仍实时校验，不能把打开商城当作付款成功。
- 退出和换号事件携带公开失效标记，各窗口可立即撤下旧身份；相同连接故障不重复通知。

## 0.7.0

- 增加有界文件预览资源及逐应用项目初始化公开接口。
- 恢复应用启动，并允许失败的运行环境释放再次清理。

## 0.6.1

- 打开应用前核对当前公开声明，入口、版本或运行环境变化时要求确认，保留原登记和业务数据。

## 0.6.0

- 增加本地应用更新核对与带确认令牌的重新登记接口，核对期间再次变化会拒绝更新。
- 应用关闭后按所属模块释放代码缓存，重新打开时消费已核对的新入口。

## 0.5.1

- 安装位置迁移后按当前登记释放环境租约，关闭应用后重试旧目录清理。
- 活动安装登记无法确认时保留租约，恢复位置后允许重试。

## 0.5.0

- 增加按技术、兼容系列和平台共享的托管运行环境及应用租约。
- 提供应用运行环境公开窄入口，关闭应用时取消初始化并释放资源。

## 0.4.0

- 增加本地应用声明检查与安装发现能力，扫描不执行应用。
- 统一应用模块入口校验，公开声明验证接口。
