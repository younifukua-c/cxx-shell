## 本批行为

安装声明只声明本应用的二级功能。主框架统一读取安装目录，保留已有顺序并追加新安装应用；当前页面不能把自己重排到一级首位。每个应用仅一个一级项，即使只提供首页也保留二级；公共消息和设置仍由框架提供。应用中心不混入安装应用目录。沿用既有中央控件、功能名称及图标，不添加新的菜单样式。

跨应用选择功能时，主进程核对入口属于该应用，再通过同一窗口激活。首次打开的目标功能可由主进程元数据恢复，不依赖页面碰巧先订阅事件；迟到与失败请求不能改写最终目标。源·派生的进程管理和部署流五个既有功能保留，原页面与草稿不销毁。

- 真实源·派生与部署流通过公开预览包验收一级目录一致，跨应用服务器与进程管理定位；最终桌面结果见本仓 .local/menu-desktop-final.log。所有实例和资料隔离且窗口隐藏，不操作用户实例。
- 本批公共接口同时涉及 @cxx/app-shell 与 @cxx/host-runtime，Changeset 为 minor。只交付源码、测试与变更记录，不发布或覆盖正式归档。
